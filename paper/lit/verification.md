### Notes on specific entries
- **zhang2026trio (arXiv 2602.04657)**: the user-supplied name "PIO-FVLM" is the **v1 title** ("PIO-FVLM: Rethinking Training-Free Visual Token Reduction for VLM Acceleration from an Inference-Objective Perspective", authors ending with Chunhua Shen). The current v3 is retitled "TRIO: Token Reduction via Inference-Objective Guidance for Efficient Vision-Language Models", and its author list changed (adds Yu Zhang, drops Chunhua Shen). The bib follows the latest version.
- **hsieh2024ruler**: arXiv v3 lists 8 authors (including Yang Zhang). The COLM 2024 OpenReview record lists 7 (no Yang Zhang). The bib uses the COLM venue record.
- **li2023selective**: the ACL Anthology author order (Li, Dong, Guerin, Lin) differs from arXiv (Li, Dong, Lin, Guerin). The bib uses the Anthology order.
- **li2025textpixels**: the arXiv title ("Text or Pixels? It Takes Half: On the Token Efficiency of Visual Text Inputs in Multimodal LLMs") differs from the Findings title. The bib uses the Findings title.
- **lee2026autoencoding** and **xu2026seer**: COLM 2026 is the Third Conference on Language Modeling, so the booktitle "Proceedings of the Third Conference on Language Modeling" extends the COLM 2024 rule.
- **wan2026rtprune**: ICML 2026 is the 43rd ICML (PMLR v306).
- **fang2026prunesid**: verified as an ICLR 2026 Poster on OpenReview.
- **devoto2025expected**: the OpenReview record shows "Submitted to ICLR 2026" (not accepted), so it is kept as arXiv.
- **cheng2025glyph**, **zhong2026focusvtc**: no accepted venue found (FocusVTC is an ICLR 2027 submission), so both are kept as arXiv.
- **Venue for Qwen2-VL / Qwen2.5-VL / Qwen3-VL / FCoT-VL / PTP / VTCBench**: no formal venue found, so all are cited as arXiv.
