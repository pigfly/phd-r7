# 一句话概念表

- **Optical context compression（光学上下文压缩）**：把长文本渲染成图片喂给 VLM，因为一张图的视觉 token 数常比同样文字的文本 token 少。
- **Vision token（视觉 token）**：图像被切成小块（patch）后，每块编码成的一个向量，计费与上下文长度都按它算。
- **Chars per vision token（字符密度）**：一个视觉 token 平均"装"了几个字符；越高越省钱，也越难读。
- **Black-box（黑盒）**：只能发输入、收输出，拿不到 logits、注意力或编码器内部状态（商用 API 就是这样）。
- **Training-free（免训练）**：方法本身不更新任何模型参数，也不训练额外的分类器。
- **Hazard gate（风险门）**：在调用模型前，仅凭文本本身判断"这段渲染成图会不会出事"的规则。
- **Shannon entropy（香农熵）**：一段字符有多"随机"；hash、UUID 熵高，英文句子熵低。
- **Verbatim span**：必须一字不差复现的片段，如哈希、ID、端口、路径。
- **Silent corruption（静默错误）**：输出错了但格式合法、看起来正常，下游察觉不到。
- **Anchor sidecar**：在图片旁边额外附上高风险片段的原文，作为"抄写参照"。
- **Check-and-retry**：把模型输出里的 verbatim 片段与原文比对，不一致就把那块改成文本重问一次。
- **Phase map / phase transition（相图 / 相变）**：随密度上升，识别准确率不是缓慢下降，而是在某个边界附近突然崩溃。
- **Causal flow query（DeepSeek-OCR 2）**：编码器里一组可学习的查询向量，用因果注意力把视觉 token 按语义阅读顺序重新排列。
- **Token pruning / merging（剪枝 / 合并）**：推理时丢掉或合并不重要的 token 以减少计算。
- **KV cache eviction**：生成时从缓存中丢弃不重要的历史 key/value，以节省显存。
- **Language prior（语言先验）**：模型对"什么文本通顺"的内置偏好；它能帮你补全看不清的英文，也会把看不清的 hash"补"成错的。
- **Viterbi**：动态规划算法，找出"像图像 × 像语言"联合概率最高的整串字符。
- **Bigram**：只用前一个字符预测下一个字符的概率表。
- **CER（字符错误率）**：解码出的字符中错了多少比例。
- **AUROC**：随机挑一个"出错"和一个"没出错"的样本，打分把出错者排在前面的概率（0.5 = 瞎猜）。
- **Rate–distortion（率失真）**：在"花多少预算"与"损失多少信息"之间做最优权衡的框架。
- **Kill criterion**：提前写好的"出现什么结果就放弃这个方向"的规则，防止事后自我说服。
- **Union bound / Gaussian tail**：v2 里用来**无标签**估计字符被认错概率的方法：把与每个形近字混淆的概率加起来。
